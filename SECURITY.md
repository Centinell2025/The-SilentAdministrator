# Security and Safety

This repository is for defensive cybersecurity education and controlled DFIR challenge development.

- Use only isolated systems owned or authorized by the author.
- Never include real credentials, tokens, customer records or personal data.
- Do not include functional malware or destructive payloads.
- Use fictional organizations, users, hosts and documents.
- Preserve evidence integrity with SHA-256 and provenance.
- Keep answer keys and author write-ups private until publication rules permit disclosure.
