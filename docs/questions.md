# Candidate Scored Questions

Exact wording and answer format are frozen only after evidence generation and independent validation.

1. Identify the first host whose evidence establishes the initial foothold.
2. Determine the earliest defensible timestamp of malicious execution.
3. Which privileged identity was abused after initial compromise?
4. What two independent artifacts prove abnormal use of that identity?
5. Identify the process chain associated with the first suspicious PowerShell execution.
6. Determine the first destination host reached using the compromised identity.
7. Which remote-administration mechanism explains that transition?
8. Identify the intermediate management host.
9. Determine the persistence mechanism established there.
10. What persistence object name was created?
11. Which evidence demonstrates that part of the event history became unavailable?
12. Identify the filesystem timestamp that cannot be trusted at face value.
13. Which independent artifact contradicts it?
14. Reconstruct the actual creation/staging interval of the suspicious archive.
15. Identify the final server reached.
16. What fictional archive was staged?
17. Where was the staging location?
18. Place all three hosts in compromise order.
19. Identify the strongest evidence distinguishing malicious `svc_backup` use from normal scheduled activity.
20. Provide the final attack sequence from foothold through staging.

Questions 1–5 orient the analyst; 6–13 require cross-host/cross-artifact correlation; 14–20 form the expert reconstruction section.
